# INSTALL — RedMoon-002 animated GitHub profile

Your package contains:
- `README.md` — the updated profile, using **local** GIFs and SVGs
- `assets/chrome-dino-chase.gif` — automatic endless-running Chrome Dino chase
- `assets/snake-autoplay.gif` — automatic looping Snake arcade animation
- `assets/contribution-snake.svg` — initial placeholder, regenerated with your real contribution history
- `.github/workflows/snake.yml` — GitHub Action that refreshes contribution snake every day

## Easiest reliable upload method (GitHub Desktop)

1. Make sure you have a **public** repository named exactly `RedMoon-002` under `RedMoon-002`.
2. In GitHub Desktop, choose **File → Clone repository** and clone `RedMoon-002/RedMoon-002`.
3. Extract this ZIP. Copy **all contents** (including hidden `.github` directory) into the cloned repository. Overwrite README.md.
4. In GitHub Desktop, commit the changes and click **Push origin**.
5. Open `https://github.com/RedMoon-002`. The two GIFs should animate immediately.
6. Open the repository's **Actions** tab, choose `Animate my GitHub contributions`, and click **Run workflow** to generate your real contribution snake. It will refresh daily after this.

## If your contribution snake isn't updating

In repository **Settings → Actions → General → Workflow permissions**, enable
**Read and write permissions**, then re-run the workflow. Repository actions must also be allowed. The workflow has `contents: write` but organization/repository settings may override it.

## Web editor alternative

To avoid using GitHub Desktop, update `README.md` on the website, add the files under their exact `assets/` paths using **Add file → Upload files**, and create `.github/workflows/snake.yml` using **Add file → Create new file**. Preserve file paths. The images will not show until the GIF files are uploaded.

## Note about 'autoplay'

GitHub profile README files don't allow running arbitrary HTML/JS games. The animations are real, infinitely looping GIFs (work immediately after upload); the activity graph snake is an animated SVG generated by GitHub Actions (requires workflow run). The snake on GitHub is animated, **not playable**.
